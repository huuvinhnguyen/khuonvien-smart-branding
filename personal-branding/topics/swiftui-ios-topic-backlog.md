## Priority topics

### IOS-001 — SwiftUI State Management: What Actually Matters?
Priority: P1
Hook: "Most SwiftUI bugs aren't about the UI. They're about state."
Focus: State ownership, observable models, unidirectional updates, asynchronous effects.
Demo idea: Device switch state: loading, confirmed, failed, and retry. Distinguish optimistic UI from device-confirmed state.

### IOS-002 — SwiftUI + Clean Architecture: How Much Is Enough?
Priority: P1
Hook: "Does every SwiftUI screen really need a Use Case and a Repository?"
Focus: Pragmatic boundaries; testing and complexity tradeoffs. Connect to the Clean Architecture topic series.

### IOS-003 — Handling API Errors in a Real SwiftUI App
Priority: P1
Hook: "A successful tap doesn't always mean a successful operation."
Focus: Network errors, timeouts, retries, loading indicators, user feedback; demo with a real, verified device action.

### IOS-004 — Async/Await and Cancellation in SwiftUI
Priority: P2
Focus: Structured concurrency, task cancellation, avoiding stale responses, main actor UI updates.

### IOS-005 — SwiftUI vs UIKit: What I Choose and Why
Priority: P2
Focus: Tradeoffs, integration, mature app constraints, performance and maintainability. Avoid blanket claims.

### IOS-006 — Dependency Injection Without Overengineering
Priority: P2
Focus: Protocols where useful, test doubles, composition roots, and simpler alternatives.

### IOS-007 — Testing SwiftUI Features Beyond the Happy Path
Priority: P2
Focus: View model/business logic tests, UI tests, connectivity failures, device behavior. Only show tests actually performed.

### IOS-008 — What Makes an iOS Engineer Senior in the AI Era?
Priority: P2
Focus: Requirements, architecture tradeoffs, code review, testing, debugging, ownership, AI assistance.
